# 動画自動投稿

動画制作・投稿を支援する、運営者本人専用のアプリです。

一般向けのサービス提供、利用者募集、第三者のGoogleアカウント連携は行っていません。このページはアプリの目的と情報の取り扱いを説明するもので、システム本体・操作画面・認証情報は公開していません。

## 主な機能

- 雑学動画の台本・音声・映像の制作支援
- 運営者が管理するYouTubeチャンネルへの動画投稿
- タイトル・説明・サムネイル・公開予定日時の設定
- 投稿先チャンネル、動画の処理状況・公開状態の確認
- 投稿記録による二重投稿の防止と障害復旧
- 別途連携したサービスを使ったTikTokへの投稿

本アプリは **YouTube API Services** を利用します。運営者本人がGoogleの認証画面で許可した範囲で、チャンネルの確認、動画のアップロード、公開設定、投稿情報の取得などを行います。

## プライバシーポリシー

### 取得・利用する情報

本アプリは、運営者本人のチャンネルを運用するため、次の情報を取り扱います。

- Googleが発行するアクセストークン・更新トークンなどの認証情報
- チャンネルID・名称・基本情報・投稿動画の一覧
- 投稿する動画・タイトル・説明・サムネイル・公開設定
- 投稿済み動画のID・処理状況・公開状態
- 二重投稿防止や障害対応に必要な処理日時・結果・エラー記録
- お問い合わせを受けた場合のメールアドレスと問い合わせ内容

これらは、動画の制作・投稿・公開確認、誤投稿や重複の防止、障害対応、お問い合わせへの返信に使用します。

### 保存と管理

認証情報と投稿管理の記録は、運営者が管理する端末・実行環境に保存し、アクセス権限を設定します。認証情報を公開リポジトリや説明サイトに掲載しません。

認証情報は継続した投稿に、投稿記録は重複防止や復旧に必要な間保持します。連携終了や保存の必要性がなくなった際は、運営者が対象データとバックアップを確認して削除します。

### 外部サービスの利用

- **Google・YouTube**：認証、動画・投稿情報の送信、投稿状態の確認に使用します。
- **Buffer・Cloudinary・TikTok**：TikTokへの投稿時に、制作した動画、投稿文、配信用URLなどを送信します。Cloudinaryの配信用URLは、URLを知る人が動画を取得できる形式で使用します。転送した動画は運営者が管理し、現在は自動削除していません。
- **制作支援サービス**：台本等の制作支援にOpenAI、音声合成にGoogle Cloud Text-to-Speech、素材の検索・取得に素材提供サービスを利用し、必要な原稿や検索語などを送信します。

Googleの認証トークンをBuffer・Cloudinary・TikTokへ渡したり、AIへの指示文に含めたりしません。

取得したGoogleユーザーデータを販売したり、広告配信・広告ターゲティングに利用したりしません。Google APIから受領した情報の利用・他のアプリへの転送は、Limited Use要件を含む[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)に従います。

外部サービスでは、それぞれの規約・プライバシーポリシーも適用されます。

- [Googleプライバシーポリシー](https://policies.google.com/privacy?hl=ja)
- [GitHubプライバシーに関する声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

### アクセス権の取り消し・データの削除

Googleへのアクセス許可は、[Googleアカウントのアクセス権管理画面](https://security.google.com/settings/security/permissions)から取り消せます。

保存した認証情報や取得情報の削除については、下記の連絡先へお問い合わせください。運営者本人が削除する場合は、該当する自動投稿処理を停止し、保存データとバックアップを確認して削除します。

アクセス権を取り消しても、端末内の保存データや投稿済み動画、登録済みの公開予約がすべて自動削除されるわけではありません。投稿や予約の削除・取り消しは、YouTube Studio、Buffer、TikTok等で別途行います。

### この説明ページについて

運営者独自の広告・アクセス解析・入力フォームは設置していません。公開基盤であるGitHubは、セキュリティ等の目的でアクセス情報を記録する場合があります。

## 利用規約

### 利用対象

本アプリは、運営者本人が管理するチャンネルのための私用ツールです。第三者への利用提供やアカウント連携は受け付けていません。

この説明ページの公開は、システム本体の配布や利用権の付与を意味しません。

### 投稿と管理

本アプリは運営者の認証・設定に基づいて動作します。投稿内容、素材の利用権限、公開範囲、公開日時は運営者が管理します。

自動処理を停止しても、外部サービスに登録済みの予約は自動で取り消されない場合があります。

### 外部サービスの利用条件

本アプリを利用する場合、[YouTube利用規約](https://www.youtube.com/t/terms)に拘束されることに同意するものとします。他の連携サービスについても、それぞれの適用される利用条件に従います。

本アプリはGoogle・YouTube・TikTok等の公式アプリではなく、各社による公認・保証を示すものではありません。

### 運用上の注意

外部サービスの仕様変更、利用上限、認証失効、通信障害等により、投稿が停止したり、予定どおり公開できなかったりする場合があります。

動画の再生数、収益化、公開時刻、継続稼働を保証するものではありません。
